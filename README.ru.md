# AmneziaWG FreeBSD Setup + Split Tunneling

Автоматизированная установка и настройка **AmneziaWG** на **FreeBSD 13/14/15** с поддержкой нативного модуля ядра и раздельного туннелирования (Split Tunneling).

В репозитории доступны две версии скрипта:
* **[`awg2-setup.sh`](awg2-setup.sh)** — Универсальная версия для классического протокола **AmneziaWG 2.0 / 1.0 (AWG2)** (обфускация `Jc`, `Jmin`, `Jmax`, `H1-H4`, `S1-S4`).
* **[`awg3-setup.sh`](awg3-setup.sh)** — Новая версия для протокола **AmneziaWG 3.1 (AWG3)** с ChaCha20-шифрованием заголовков (`HeaderProtectionKey`), динамическим транспортным паддингом (`ContentPaddingAddition`), защитой от поведенческого анализа (AI DPI) и контролем версий пакетов.

---

## Возможности

* **Нативная производительность ядра**: Работа через официальный модуль ядра FreeBSD `if_amn.ko` (пакет `net/amnezia-kmod`).
* **Без необходимости ручной сборки**: Установка готовых утилит и модулей напрямую через менеджер пакетов `pkg` (с возможностью сборки из дерева портов при необходимости).
* **Раздельное туннелирование (Split Tunneling)**: Маршрутизация трафика только для выбранных доменов и IP/CIDR-подсетей через `Table = off` и нативные маршруты FreeBSD без разрыва соединений при ротации IP-адресов.
* **Автозапуск сервиса (rc.d)**: Автоматический старт туннеля при загрузке системы (`service amneziawg` / `service amneziawg3`).
* **Безопасная очистка (`-u`)**: Полное и корректное удаление конфигураций, сервисов и модулей без повреждения системных настроек загрузчика.

---

## Системные требования

1. **ОС**: FreeBSD 13.0, 14.x или 15-CURRENT.
2. **Права**: Запуск от имени **root** (или через `sudo`).
3. **Конфигурация**: Рабочий `.conf` файл AmneziaWG от вашего провайдера или сервера.

## Установка и использование

### Интерактивный TUI-мастер (Рекомендуется)

Запустите скрипт с правами root без аргументов — автоматически откроется фирменный диалоговый мастер FreeBSD (`bsddialog`):

```bash
# Для AmneziaWG 3.1:
sudo ./awg3-setup.sh

# Для AmneziaWG 2.0 / 1.0:
sudo ./awg2-setup.sh
```

Пошаговый мастер проведёт вас через:
1. **Выбор языка**: Русский или Английский.
2. **Поиск конфигурации**: Автоматический поиск файлов `.conf` в текущей папке, `$HOME` и `/etc` (либо ручной ввод пути).
3. **Режим маршрутизации**: Полный туннель или раздельное туннелирование.
4. **Менеджер доменов**: Удобное добавление/удаление доменов и подсетей в TUI перед установкой.
5. **Автоматическая верификация**: Проверка рукопожатия, маршрутов к целевым доменам и внешнего IP на финальном экране.

### Режим командной строки (CLI / без диалогов)

Вы также можете передать аргументы напрямую для автоматизированной настройки:

#### 1. Версия AmneziaWG 2.0 / 1.0 (AWG2)

```bash
# Полный туннель (весь интернет через VPN):
sudo ./awg2-setup.sh -c /путь/к/vpn.conf

# Раздельное туннелирование (только для выбранных доменов и подсетей):
sudo ./awg2-setup.sh -c /путь/к/vpn.conf -d "rutracker.org,nnmclub.to,198.51.100.0/24"
```

#### 2. Новая версия AmneziaWG 3.1 (AWG3)

Для конфигураций с параметрами `HeaderProtectionKey`, `ContentPaddingAddition` и `RandomTrailers`:

```bash
# Полный туннель AWG 3.1:
sudo ./awg3-setup.sh -c /путь/к/awg3.conf

# Раздельное туннелирование AWG 3.1:
sudo ./awg3-setup.sh -c /путь/к/awg3.conf -d "rutracker.org,nnmclub.to"
```

## Параметры командной строки

| Опция | Описание |
| :--- | :--- |
| `-c FILE` | **(Обязательно)** Путь к `.conf` файлу AmneziaWG. |
| `-d TARGETS` | Опциональный список доменов или IP/CIDR через запятую для раздельного туннелирования. *(По умолчанию: весь трафик идёт через VPN)*. |
| `-i IFACE` | Имя сетевого интерфейса. *(По умолчанию: `awg0`)*. |
| `-u` | Полное удаление сервиса, конфигураций и модулей. |
| `-h` | Вызов справки по опциям. |

## Управление сервисами

Туннель автоматически восстанавливается после перезагрузки ОС благодаря интеграции с системой `rc.d`.

### Классический сервис (`amneziawg`):
```bash
service amneziawg start    # Запустить VPN
service amneziawg stop     # Остановить VPN
service amneziawg status   # Проверить статус
awg show awg0              # Подробная информация об интерфейсе и пирах
```

### Сервис AWG 3.1 (`amneziawg3`):
```bash
service amneziawg3 start   # Запустить VPN AWG 3.1
service amneziawg3 stop    # Остановить VPN AWG 3.1
service amneziawg3 status  # Проверить статус
awg show awg0              # Подробная информация об интерфейсе и пирах
```

  `netstat -rn | grep awg0`
